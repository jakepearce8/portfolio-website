Privacy

Privacy policy

Effective date: 22 October 2026

This policy explains how the Record Preview Chrome extension handles information. Record Preview is an independent project by Jake Pearce. It helps you find and play music previews for record listings on supported websites.

Information the extension reads

When Record Preview is enabled on a supported shop, it reads listing details needed to identify a release, such as artist, album or track title, product text, and artwork shown on the page. This processing happens in your browser to create a preview search and display the result. The extension does not need your shopping account credentials or payment details.

Information sent to other services

  • YouTube Data API: When a preview search is made, the extension sends the artist and release or track search terms, the API key being used, and the API request to Google’s YouTube Data API. Google returns candidate video information such as titles, channel names, thumbnails, and video IDs.
  • YouTube embedded player: When a preview is shown or played, the extension loads YouTube’s embedded player. Google may receive technical information such as your IP address, browser/device information, and player interactions. Google’s own privacy terms and settings apply to that service.
  • Discogs: On Discogs pages, the extension may request release metadata from Discogs’ API using the relevant Discogs release, master, or listing identifier so it can display the release tracklist and related details.

Record Preview does not send browsing history to a server operated by the project author. Search requests are made to the services above to provide the preview features.

Searches and preferences

Record Preview uses the YouTube Data API credential configured for the extension. You do not need to create or enter an API key. When a preview search is made, Google receives the search terms and the extension’s API credential to return candidate videos. Searches use the quota assigned to the extension’s Google Cloud project.

If you are updating from an earlier version that let you enter a personal API key, that saved key is removed from local extension storage when the updated extension runs.

Your excluded search terms, preview enable/disable preference, and cached preview results are stored locally by Chrome. The preview cache expires after a limited period to reduce repeated searches.

Retention and controls

Settings and cached preview data remain in your browser until you change or clear them, the cache expires, or you remove the extension. You can change excluded search terms, turn previews off from the extension popup, clear Chrome extension data, or uninstall the extension.

Children’s privacy

Record Preview is a shopping companion for people browsing music listings and is not designed to collect information from children.

This policy may be updated when the extension’s features or data practices change. The effective date above will be revised when an update is made.
